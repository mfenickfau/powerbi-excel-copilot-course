# AI in Excel

Every AI feature in and around Excel as of November 2026: Copilot modes and skills, agents, built-in AI without Copilot, Python in Excel, data preparation, Power BI and Fabric, and outside AI tools. Uncertain features are marked Verify before class.

## Folder layout

Each module folder has `slides/` (the module deck, with demos in the speaker notes), `handouts/` (the lab book for that module, plus any lab documents) and `workbooks/` (the data files the labs use). `00-start-here` has the course introduction, Lab 0 setup, the answer key and the closing slides. `full-course/` has the whole deck and lab book in one file each.

|---|---|

| Microsoft 365 Copilot licence (or Personal, Family, Premium) | Modules 2 to 5 and lab 7.3. Labs 3.9, 4.1 and 4.3 need the full business licence. |
| Insider or Frontier enrolment | Labs 3.10, 3.12, 3.13, 5.1 and 7.5, and the @python-in-excel skill. |
| Microsoft 365 Business or Enterprise | Python in Excel, full Power Query on the web, Office Scripts. |
| Power Automate with Copilot Credits | Labs 8.3 to 8.5. AI Builder credits were replaced on 1 Nov 2026. |
| Power BI or Fabric access | Module 9 and lab 4.3. |
| Approved outside AI accounts | Labs 10.1, 10.3 and 10.4 (Claude, ChatGPT, Gemini). |
